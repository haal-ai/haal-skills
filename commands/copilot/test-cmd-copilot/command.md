# test-cmd-copilot

A Copilot prompt file. Invoke with `/test-cmd-copilot` in VS Code Copilot chat.

Summarizes the current file `${file}` and lists any obvious issues.

1. Read `${file}` carefully
2. Write a one-paragraph summary of what it does
3. List up to 3 potential issues or improvements
