# carry-over-session

Create a simple carry-over note with next prompt and files needed for session continuation.

## Usage

Run this skill at the end of a session to save context for the next one.

## Steps

1. Summarize what was accomplished in this session
2. Identify the immediate next action
3. List files that will be needed
4. Write a carry-over note to `.olaf/work/carry-over-<timestamp>.md`
