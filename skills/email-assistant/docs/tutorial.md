# email-assistant

> Step-by-step tutorial for drafting, replying, and rewriting emails

## Prerequisites
- Text to work with (email to reply to, notes for a draft, or draft to rewrite)

## Estimated Time
2–5 minutes

## Step-by-Step Instructions

### Step 1: Choose Your Mode
Tell the assistant what you need:
- **Draft**: "Draft an email about the Q3 roadmap changes"
- **Reply**: "Reply to this email" (then paste the email)
- **Rewrite**: "Rewrite this email to be more concise" (then paste the draft)

### Step 2: Paste Your Content
If not already provided, paste the email or notes when prompted. No file paths needed — just paste directly into the chat.

### Step 3: Select Tone
Choose from the menu:
1. **Professional** — formal, concise, no slang
2. **Friendly** — warm but still professional
3. **Friends** — casual, short, informal

### Step 4: Select Conciseness
Choose from the menu:
1. **Very short** — 2-5 sentences
2. **Short** — 1 paragraph + optional bullets
3. **Medium** — 2-3 short paragraphs
4. **Long** — up to 250-350 words, structured

### Step 5: Choose Language (Optional)
Default is English. Select another language if needed (French, Spanish, etc.).

### Step 6: Review the Draft
The skill presents:
- **Subject line** appropriate to tone
- **Email body** with greeting, context, message, call to action, and closing

Review for accuracy and tone. Request changes if needed.

### Step 7: Approve and Save
Confirm to save the email to the staging file.

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Wrong tone | Re-run with a different tone selection |
| Email too long/short | Change the conciseness parameter |
| Missing context | Provide more details in your initial notes |
| Wrong language | Specify the language explicitly |

## Verification Checklist
- [ ] Mode, tone, and conciseness confirmed
- [ ] Subject line is appropriate
- [ ] Email body matches requested tone and length
- [ ] No fabricated information
- [ ] Saved to staging file (if approved)
