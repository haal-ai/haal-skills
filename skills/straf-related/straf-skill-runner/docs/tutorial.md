# straf-skill-runner

> Step-by-step tutorial for running OLAF skills via STRAF

## Prerequisites
- STRAF agent installed and accessible
- OLAF skills available in the registry

## Estimated Time
5–10 minutes (depends on selected skill)

## Step-by-Step Instructions

### Step 1: Launch the Runner
> "Run an OLAF skill via STRAF"

### Step 2: Browse Available Skills
A list of available skills is presented. Review and select one.

### Step 3: Provide Parameters
The runner reads the selected skill's requirements and prompts for each parameter. Required parameters must be provided; optional ones can be skipped.

### Step 4: Choose Execution Mode
- **Spawn**: Background execution (recommended for long-running skills)
- **Interactive**: Direct interaction with the skill

### Step 5: Review Results
Output from the skill execution is displayed.

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Skill not found | Verify skill exists in the registry |
| Missing parameters | Provide all required parameters |
| STRAF agent not responding | Check STRAF installation and status |

## Verification Checklist
- [ ] Skill selected from available list
- [ ] All required parameters provided
- [ ] Execution completed successfully
- [ ] Output reviewed
