# test-straf

> Step-by-step tutorial for running STRAF integration tests

## Prerequisites
- STRAF agent installed and accessible
- A codebase to test against

## Estimated Time
5 minutes

## Step-by-Step Instructions

### Step 1: Invoke the Test
> "Run STRAF integration test"

The skill follows a strict sequential chain protocol.

### Step 2: Language Detection
STRAF detects the project's primary language automatically.

### Step 3: Context Preparation
Relevant code context is gathered for the STRAF review.

### Step 4: Execute STRAF Review
The STRAF agent performs its analysis on the prepared context.

### Step 5: Review Results
Test results are displayed showing whether STRAF integration is functioning correctly.

## Troubleshooting

| Issue | Solution |
|-------|----------|
| STRAF not found | Verify STRAF installation |
| Language not detected | Specify language manually |
| Review fails | Check STRAF agent logs for errors |

## Verification Checklist
- [ ] Language correctly detected
- [ ] Context successfully prepared
- [ ] STRAF review completed
- [ ] Results displayed correctly
